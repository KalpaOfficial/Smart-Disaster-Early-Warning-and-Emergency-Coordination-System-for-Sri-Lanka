# 🚨 Smart Disaster Early-Warning and Emergency Coordination System

A digital disaster management platform designed to improve **early warning, emergency coordination, and disaster response in Sri Lanka**.

This project is developed as part of the **BSc (Hons) in Software Engineering – SE3070 Case Studies in Software Engineering, 2026 Semester 2**.

## 📌 Overview

Sri Lanka faces recurring disasters such as floods, landslides, cyclones, droughts, and other emergencies. During these situations, communication between citizens, government agencies, responders, shelters, and relief organizations can become fragmented.

Our system aims to provide a **unified platform** that allows authorities to issue location-specific warnings, verify citizen hazard reports, coordinate emergency resources, and monitor disaster response from a centralized system.

## 🎯 Main Objectives

* 📢 Issue timely and location-specific disaster warnings
* 📍 Allow citizens to report hazards with GPS locations and photos
* ✅ Allow authorized officers to verify hazard reports
* 🏠 Manage emergency shelters and occupancy
* 🚑 Coordinate rescue teams and emergency missions
* 📦 Track relief resources and distributions
* 🤝 Coordinate government agencies, NGOs, volunteers, and other organizations
* 📴 Support basic offline reporting during network disruptions
* 📊 Provide disaster analytics and post-event reports

## 🏗️ System

The platform consists of:

### 📱 Citizen & Responder Mobile App

Built with **React Native + Expo + TypeScript**

Used by:

* Citizens
* Field responders
* Volunteers

### 💻 DMC Web Dashboard

Built with **React + TypeScript**

Used by:

* DMC Officers

### ⚙️ Backend

Built with:

* Firebase Authentication
* Firebase Firestore
* Firebase Storage

## 🔄 Core Workflow

```text
Hazard Occurs
      ↓
Citizen / Responder Report
      ↓
DMC Verification
      ↓
Disaster Event
      ↓
Official Warning
      ↓
Citizen Notification
      ↓
Emergency Response
      ↓
Shelters + Rescue Teams + Resources
      ↓
Analytics & Reports
```
